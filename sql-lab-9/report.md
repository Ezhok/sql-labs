# Модуль 9. Лабораторная работа «Витрины аналитика»: представления, CTE и табличные функции

**Курс:** «Углублённый SQL»  
**Вариант:** 2, команда Б «Производство и закупки»  
**Личная схема:** `stud_komanda_b`  
**Схема с исходными данными:** `pitanie`

## Цель работы

Создать аналитические представления, материализованное представление, CTE-цепочки, рекурсивный CTE и табличные функции. Использовать подготовленные витрины для анализа качества производства, закупочных цен, перерасхода сырья, простоев и потерь предприятия.

## Подготовка

Для работы используется личная схема `stud_komanda_b`. Исходные данные читаются из схемы `pitanie`, а создаваемые представления и функции размещаются в личной схеме.

В начале скрипта устанавливается порядок поиска схем:

```sql
SET search_path TO stud_komanda_b, pitanie, public;
```

Объекты создаются с помощью `CREATE OR REPLACE` или предварительного удаления через `DROP ... IF EXISTS`. Для объектов добавляются комментарии.

## Б3. Материализованное представление `mv_material_overuse`

Создано материализованное представление для сравнения нормативного и фактического расхода материалов по производственной линии, смене и материалу.

- нормативный расход по рецептурам;
- фактический расход по производственным партиям;
- средняя закупочная цена материала.

Для ускорения обновления создан уникальный индекс по полям `line_id`, `shift`, `material_id`. После создания индекса выполнено обновление через `REFRESH MATERIALIZED VIEW CONCURRENTLY`.

## Б4. CTE-цепочка «Стоимость потерь производства 2025»

С помощью нескольких CTE рассчитаны потери по производственным линиям и списания сырья.

В расчёт включены:
- стоимость брака;
- продолжительность простоев;
- оценка стоимости простоев через мощность линии и маржу;
- списания сырья.

| Объект | Стоимость брака, млн ₽ | Простой, ч | Стоимость простоя, млн ₽ | Всего, млн ₽ |
|---|---:|---:|---:|---:|
| Линия 2 | 2,31 | 590,1 | 24,53 | 26,84 |
| Линия 1 | 1,06 | 50,0 | 12,89 | 13,95 |
| Линия 4 | 0,82 | 69,2 | 8,78 | 9,60 |
| Линия 3 | 2,47 | 57,5 | 6,73 | 9,20 |
| Линия 5 | 1,00 | 29,1 | 3,69 | 4,68 |
| Списания сырья | — | — | — | 0,88 |

Наибольшие расчётные потери приходятся на линию № 2: около 26,84 млн ₽, из которых 24,53 млн ₽ связаны с простоями.

В работе отдельно отмечено ограничение оценки: расчёт по формуле «часы простоя × паспортная мощность» может завышать потери, поскольку линия не работает круглосуточно и не всегда загружена на полную мощность. Для уточнения оценки предлагается учитывать только простои внутри смен и использовать фактическую часовую выработку.
