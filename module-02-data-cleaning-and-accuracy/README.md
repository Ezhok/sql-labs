# Модуль 2. Приводим данные в порядок и считаем точно

Лабораторная работа по курсу «Углублённый SQL».

- **СУБД:** PostgreSQL 16
- **Вариант:** Команда Б, вариант 2 «Производство и закупки»
- **Дата среза:** 31.12.2025

## Содержание

- `sql/lab02_team_b.sql` — SQL-запросы с комментариями для заданий О1–О2 и Б1–Б9.
- `report.md` — результаты выполнения, аналитические наблюдения и вывод для руководства.

## Запуск

Подключитесь к базе данных с учебной схемой `pitanie` и выполните SQL-файл в PostgreSQL 16.

В начале файла задаются параметры окружения:

```sql
SET search_path TO pitanie, public;
SET lc_time = 'ru_RU.UTF-8';
```

В запросах используется фиксированная дата среза. `CURRENT_DATE` не применяется.

## Основные результаты

- Все 10 наиболее продолжительных закрытых простоев относятся к линии 2.
- Время простоев линии 2 выросло с 168,4 часа в 2024 году до 590,1 часа в 2025 году.
- Дробный расчёт выявил 627 партий с браком выше 5%, целочисленный — 625.
- Проверка номера партии выявила 0 несоответствий.
- 36 позиций поставщика ООО «МолПром Регион» опоздали минимум на 4 дня.
- Сумма списаний клубничного наполнителя по причине истечения срока годности составила 1 151 630,53 рубля.

Подробности и ограничения интерпретации приведены в `report.md`.
