# Модуль 3. Извлечение данных из нескольких таблиц

**Команда Б, вариант 2: «Производство и закупки»**

## Описание

Лабораторная работа посвящена извлечению и анализу данных из нескольких связанных таблиц с помощью SQL-запросов в PostgreSQL.

В ходе работы применялись:
- `INNER JOIN` — соединение связанных записей
- `LEFT JOIN` — сохранение записей основной таблицы при отсутствии связанных данных
- `SELF JOIN` — сравнение записей одной таблицы между собой
- `CROSS JOIN` — создание всех комбинаций дат, производственных линий и смен

## Задания

- **Б1.** Производственные партии за 2025 год
- **Б2.** Партии с высоким процентом брака
- **Б3.** Ответственные за производственные линии и их руководители
- **Б4.** Анализ поставок сахара
- **Б5.** Сравнение закупочных цен разных поставщиков
- **Б6.** Опоздания и качество поставок
- **Б7.** Анализ простоев оборудования
- **Б8.** Сравнение нормативного и фактического расхода сырья
- **Б9.** Анализ списаний материалов
- **Б10.** Поиск пропущенных производственных смен
