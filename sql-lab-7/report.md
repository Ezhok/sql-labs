### Б5. Обновление норм расхода с помощью UPSERT

Перед обновлением в таблице `recipes` находилось 146 записей.

Первая попытка выполнить `INSERT ... ON CONFLICT DO UPDATE` завершилась ошибкой:

`ON CONFLICT DO UPDATE command cannot affect row a second time`

Причина ошибки: в исходной таблице `recipe_norms_2026` пара `(product_id, material_id) = (8, 10)` встречалась дважды, в строках с `line_no = 1` и `line_no = 12`.

Для устранения проблемы использован `DISTINCT ON` с сортировкой по `line_no DESC`. Для каждой пары выбиралась последняя строка источника.

При обновлении добавлено условие `IS DISTINCT FROM`, чтобы изменять только действительно отличающиеся нормы расхода.

Для контроля результата использован `RETURNING` с выражением `(xmax = 0) AS inserted`, позволяющим различить вставленные и обновлённые записи.

**Результаты:**

| Операция | Количество |
|---|---:|
| Новые записи | 4 |
| Обновлённые записи | 4 |
| Всего обработано | 8 |
| Итоговое количество записей в `recipes` | 150 |

Записи без изменений не обновлялись.

### Б6. Формирование стоп-листа поставщиков

**Критерий 1. Переплата более 15%**

Рассчитаны средневзвешенные закупочные цены по материалам за 2025 год и сопоставлены с минимальными средними ценами других поставщиков по тем же материалам.

В стоп-лист включён ООО «АгроСнаб-М».

Результат:

- максимальное превышение составляет 27%.

**Критерий 2. Опоздания поставок**

Рассчитана средняя задержка поставок за 2025 год по разнице между `received_date` и `expected_date`.

В стоп-лист включено ООО «МолПром Регион» со средней задержкой 2,8 дня.

При повторном обнаружении поставщика используется `ON CONFLICT`, позволяющий дополнить существующую причину включения в стоп-лист.

**Итоговый стоп-лист:**

## 5. Вывод

В ходе лабораторной работы были применены основные операции изменения данных PostgreSQL: `INSERT`, `UPDATE`, `DELETE`, `UPSERT` и `MERGE`.

Анализ коммерческих предложений показал возможность снизить закупочные цены по 9 парам «поставщик — материал». Расчётная экономия на объёмах закупок 2025 года составляет около 3,1 млн рублей. Три предложения с повышением цены не были приняты, а предложение ООО «ВкусЭкспорт» исключено из обработки, поскольку поставщик отсутствует в справочнике.

После сбоя интеграции WMS было обнаружено 18 дублирующих записей приёмки на общую сумму 2 570 703,33 руб. Ошибочные записи удалены, что позволило восстановить корректное количество записей о приёмке.

В стоп-лист включены ООО «АгроСнаб-М» из-за переплаты по 10 материалам до 27% и ООО «МолПром Регион» из-за средней задержки поставок 2,8 дня. Расчётная переплата по закупкам у ООО «АгроСнаб-М» за 2025 год относительно лучших средних цен составила около 1,99 млн рублей.

Четыре незакрытых простоя оборудования получили расчётное время окончания на основе средней длительности аналогичных простоев с соответствующей отметкой об оценочном характере данных.

При обновлении рецептурных норм было добавлено 4 новых записи и изменено 4 существующих. При этом корректировка норм сама по себе не устраняет избыточные закупки сырья. Для снижения списаний необходимо сопоставлять закупочные объёмы с фактическим потреблением.

Проверка отказа от ООО «АгроСнаб-М» показала наличие альтернативных поставщиков по всем материалам из его контрактного списка. Перед фактическим прекращением сотрудничества необходимо дополнительно оценить возможности альтернативных поставщиков по объёмам и срокам поставок.
