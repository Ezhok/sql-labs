# Лабораторная № 1. Структура БД и бизнес-процессы

**Команда Б — «Производство и закупки»**

## Состав

- `report.md` — ответы, расчёты и выводы по лабораторной.
- `sql/` — SQL-запросы, сгруппированные по разделам.
- `diagrams/business-process.mmd` — схема процессов закупки и производства в Mermaid.

## Запуск

1. Откройте подключение к учебной базе PostgreSQL в DBeaver.
2. Откройте нужный `.sql`-файл.
3. Проверьте, что подключение ведёт к учебной БД.
4. Выполните запросы по порядку и при необходимости замените значения фильтров.
5. Не запускайте команды изменения данных: лабораторная работает с учебной схемой только на чтение.

В начале SQL-файлов задан `search_path` на схему `pitanie`.

## Примечание

Результаты запросов и выводы приведены в `report.md`. Если данные в учебной базе изменятся, повторный запуск запросов может дать другие результаты.
