# SQL Labs

Репозиторий с выполненными лабораторными работами по курсу **«Углублённый SQL»**.

В рамках курса выполнены 9 лабораторных работ, посвящённых работе с PostgreSQL, обработке данных и аналитическим SQL-запросам.

## Лабораторные работы

1. **Лабораторная № 1** — структура БД и бизнес-процессы
2. **Лабораторная № 2** — фильтрация и сортировка данных
3. **Лабораторная № 3** — извлечение данных из нескольких таблиц
4. **Лабораторная № 4**
5. **Лабораторная № 5**
6. **Лабораторная № 6**
7. **Лабораторная № 7** — наводим порядок в данных
8. **Лабораторная № 8** — динамика, рейтинги и ABC-анализ
9. **Лабораторная № 9** — витрины аналитика: представления, CTE и табличные функции

## Используемые технологии

- PostgreSQL 16
- DBeaver
- SQL
- Git и GitHub

## Важно

- Учебная схема `pitanie` используется только для чтения.
- Для выполнения лабораторных используются отдельные пользовательские схемы.
- Не добавляйте в репозиторий пароли, сертификаты, строки подключения и другие конфиденциальные данные.
